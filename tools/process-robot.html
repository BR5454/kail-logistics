🤖 Process Robot

Kisi bhi website pe ek baar process karke dikhao, phir poori list ka data robot khud search karke Excel me de dega.

1. Download karo

⬇ Process Robot download (Chrome ke liye)

Size ~15 KB. Sirf Google Chrome / Microsoft Edge pe chalta h (laptop/computer). Mobile pe nahi.

2. Chrome me lagao (sirf pehli baar, 2 minute)

  1. Download hui process-robot.zip pe right-click → Extract All (folder ban jayega process-robot).
  2. Chrome me address bar me likho chrome://extensions aur Enter.
  3. Upar right me Developer mode ON karo.
  4. Load unpacked button dabao → process-robot folder chuno (jisme manifest.json h).
  5. Chrome ke upar puzzle 🧩 icon → Process Robot ke aage 📌 pin karo.
  6. Jo tab pehle se khule the unhe ek baar refresh kar lo.

3. Kaise use kare

1Sikhao

Jis website pe search karna h wahan jao. Robot icon dabao → Recording shuru. Search box me ek sample number likho, Search dabao. Result aaye to + Data uthao dabake jo cheezein chahiye un pe click karo (ya + Poori table uthao). Phir Recording band karo.

2Chalao

2. Chalao tab me apni list paste karo (har line me ek entry, Excel se copy-paste chalega). ▶ Chalao dabao. Robot har entry ke liye khud page kholega, likhega, search karega aur data uthayega.

3Result

3. Result tab me ⬇ Excel/CSV download dabao. Har entry ki ek line (table ho to har table row ki ek line) + Status column (OK / ERROR).

Zaroori tips

  1. Search box wale step ke aage dropdown me “List se (column 1)” hona chahiye, tabhi har baar list ki nayi entry likhi jayegi.
  2. Excel se 2 column copy karoge (jaise Vehicle No + Mobile) to wo column 1 aur column 2 ban jayenge. Dusre box ke step me “List se (column 2)” chuno.
  3. Website slow ho to + Ruko (sec) step jodo, ya “Click ke baad ruko” seconds badhao.
  4. Captcha / OTP wali site: Search se pehle + Captcha/OTP ke liye ruko step jodo. Robot wahan rukega, aap captcha bharo aur Continue dabao.
  5. Robot chalte waqt us tab ko band mat karo aur mouse se page pe kuch mat karo. Beech me roka to baad me “Entry N se aage chalao” se wahi se shuru hoga.
  6. Pehle 2-3 entries se test karo, sab sahi aaye tab poori list chalao.

Dost / doosre ka laptop: kaam ke baad Result download karke “Sab kuch mitao” dabao, phir chrome://extensions me Process Robot ko Remove kar do aur Developer mode OFF kar do.
