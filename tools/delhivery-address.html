📦 Delhivery Address Nikalo

WBN / UC ID ki list do → har ID ka Name, Address, Pincode, Mobile Excel me. Kuch sikhana nahi, extension nahi.

1. Bookmark banao (sirf pehli baar)

  1. Chrome me Ctrl + Shift + B dabao (bookmarks bar dikhega).
  2. Neeche wale green button ko mouse se pakad ke bookmarks bar pe chhod do (drag & drop). Click nahi karna.

📦 Delhivery Address

Drag na ho to: → bookmarks bar pe right-click → Add page → Name: Delhivery Address, URL me paste → Save.

2. Use kaise kare

  1. Delhivery panel (Kail login) me kisi bhi ek shipment ka page kholo, jaisa normally WBN search karke khulta h.
  2. Bookmarks bar me 📦 Delhivery Address dabao. Right side me lal panel khulega.
  3. Panel me hara box dikhe: "Is page pe check: 110-Royalica | G-40… | 395010 | 0846…" → matlab sahi padh raha h.
  4. List box me saari WBN / UC ID paste karo (Excel column copy-paste chalega, duplicate apne aap hat jayenge).
  5. ▶ Start dabao. Ek chhoti popup window khulegi, har ID ka page usme khulega. Popup band mat karna.
  6. Khatam hone pe ⬇ Excel/CSV download.

Popup block ho jaye to address bar ke right side popup icon pe click → Always allow → dobara Start. Beech me ruk jaye to wahi bookmark dobara dabao aur "se aage chalao". Kisi ID me ERROR aaye to CSV ke "Debug text" column ka screenshot bhejo.

Console se chalana (agar bookmark na chale)

Shipment page pe F12 → Console → allow pasting likh ke Enter (pehli baar) → ye code paste karke Enter.
